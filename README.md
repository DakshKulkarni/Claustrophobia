# SCP Maze Runner (VR)

## Project Overview  
This project is a VR horror escape game built using **Unity 2022.3.19f**, **XR Interaction Toolkit**, and **Meta Quest 3** support.  
The game draws inspiration from the **SCP universe**, where the player is trapped inside a maze filled with anomalies and must find an escape route before being caught.  

It features:  
- A **Start Scene** that transitions into the Maze.  
- **Immersive SCP-inspired atmosphere** with eerie sound and lighting design.  
- **First-person VR controls** for walking, running, and interacting.  
- A basic **objective system** where the player searches for the exit while avoiding anomalies.

## Setup Instructions  

### Requirements  
- Unity version: `2022.3.19`  
- Any Meta Quest device
- XR Interaction Toolkit installed and configured  
- Android Build Support enabled for Unity  

### How to Test  
1. Clone or download this repository.  
2. Open the project in Unity Hub (Unity 2022.3.19 recommended).  
3. Switch the build platform to **Android** for Quest.  
4. Connect your Meta Quest headset via Link or Wi-Fi(only Windows).
5. Build and Run on Android.  

---

## Game Controls  
- **Movement:** Joystick (Quest controller)  
- **Look Around:** Head tracking  
- **Interact:** Trigger button  
- **Objective:** Navigate the maze and find the exit while avoiding anomalies  

---

## Bugs & Notes  
- Sometimes colliders may cause the player to float instead of fall when leaving the bridge gaps. This is being refined.
- There is no exit point as of now, working on this to refine the experience further.

---

## Build  
If you want to build yourself:  
1. Clone/download the project.  
2. Open in Unity 2022.3.19.  
3. Ensure XR Interaction Toolkit is properly set up.  
4. Build and Run for Android.

## Developer Notes  
This project was our attempt to create a **VR SCP-inspired maze escape experience**. It started as an experiment to test procedural generation and horror elements inside VR for a research project, but it grew into a proper game prototype.  
We faced challenges with XR interactions, colliders, and physics inconsistencies, but these helped me learn a lot about VR mechanics(there are still some).  
Although the game is still basic in visuals and design, it set the foundation for expanding into more advanced SCP-inspired VR projects.
